# 常见问题

## 会改变我的 Codex 模型或配置吗？

不会。项目不会读取或写入 `~/.codex/config.toml`，不会切换模型，也不会重启或控制 Codex。

## 数据多久更新一次？

启动时立即更新，之后每 10 分钟刷新。网络暂时不可用时会使用本机缓存；缓存也不可用时显示 `—`。

## 为什么显示的模型和顺序会变化？

每次刷新后都会重新计算全部公开模型档位。IQ 达到 80 的模型按 `IQ ÷ 费用` 从高到低显示，并只保留前三名；IQ 未达标的模型固定靠后。

## 为什么某个模型费用更低却排在后面？

若该模型的 IQ 小于 80，它不会排在达标模型之前。若都已达标，则会比较 IQ÷费用，而不是只比较费用。

## 为什么显示 `—`？

公开数据请求和本机缓存都不可用，或公开数据暂时没有有效的模型档位记录。检查网络后等待下一次自动刷新即可。

## 如何调整 IQ 门槛或显示数量？

编辑 [config.py](../src/codex_tier_widget/config.py) 的 `MINIMUM_IQ` 或 `DISPLAY_LIMIT`，然后重启悬浮窗。

## 如何隐藏或退出程序？

按 `Escape` 或在托盘菜单选择“隐藏悬浮窗”，只会隐藏窗口，程序仍会继续刷新数据。要完全退出，请右键右下角托盘图标，选择“退出程序”。

## 如何关闭或开启开机自启？

右键托盘图标，点击“开机自启”。菜单前有勾表示已开启；没有勾表示已关闭。该设置只写入当前用户的 Windows 启动项，不需要管理员权限。

## 为什么首次运行就会开机自启？

这是项目的默认行为。首次运行后，用户可随时通过托盘菜单关闭；关闭后程序会记住选择，不会在下次手动运行时重新开启。

## 为什么看不到托盘图标？

Windows 可能将图标收进通知区域的“显示隐藏图标”菜单，请在那里查找 Codex 档位图标。

从源码运行时，还需要先安装依赖：

```powershell
python -m pip install -r requirements.txt
```

## Windows 为什么提示未知发布者？

当前 EXE 尚未使用商业代码签名证书。请只从本项目的 GitHub Releases 下载，并可用同一发布页提供的 SHA-256 文件核对完整性。
