# 常见问题

## 会改变我的 Codex 模型或配置吗？

不会。项目不会读取或写入 `~/.codex/config.toml`，不会切换模型，也不会重启或控制 Codex。

## 数据多久更新一次？

启动时立即更新，之后每 10 分钟刷新。网络暂时不可用时会使用本机缓存；缓存也不可用时显示 `—`。

## 为什么模型顺序会变化？

每次刷新后都会重新计算排序。IQ 达到 80 的模型按 `IQ ÷ 费用` 从高到低显示；IQ 未达标的模型固定靠后。

## 为什么某个模型费用更低却排在后面？

若该模型的 IQ 小于 80，它不会排在达标模型之前。若都已达标，则会比较 IQ÷费用，而不是只比较费用。

## 为什么显示 `—`？

公开数据请求和本机缓存都不可用，或数据源中不存在该模型与推理强度的组合。检查网络，或确认 `TIERS` 中的 `model`、`effort` 与数据源一致。

## 如何调整 IQ 门槛或模型档位？

编辑 [config.py](D:/codering_widget/src/codex_tier_widget/config.py) 的 `MINIMUM_IQ` 或 `TIERS`，然后重启悬浮窗。

## 如何关闭悬浮窗？

将窗口置于前台后按 Escape，或在任务管理器中结束对应的 Python 进程。
