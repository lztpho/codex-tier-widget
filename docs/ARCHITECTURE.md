# 架构说明

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `widget.py` | 三行紧凑界面、鼠标拖动、刷新排序、显示隐藏与退出生命周期 |
| `data.py` | 拉取公开数据、本地缓存、查找模型记录 |
| `color.py` | IQ/费用分数、格式化与辅助颜色 |
| `config.py` | 显示数量、IQ 门槛、数据地址与界面尺寸 |
| `tray.py` | 系统托盘图标、托盘菜单与后台命令队列 |
| `autostart.py` | 当前用户开机自启注册表状态、路径刷新与切换 |
| `scripts/launch_widget.py` | 从项目源码可靠启动悬浮窗 |
| `CodexTierWidget.spec` | PyInstaller 单文件 Windows EXE 构建配置 |

## 数据流

```text
启动或十分钟刷新
        ↓
读取 Codex 雷达实时任务表 API
        ↓
按网页规则聚合每个模型档位的 IQ 与费用
        ↓ 失败
读取本机缓存；首次运行无缓存时再读取旧公开快照
        ↓
读取全部公开模型档位的 IQ 与费用
        ↓
按 IQ 80 门槛分组，再按 IQ ÷ 费用排序并选择前三名
        ↓
渲染模型短名称、IQ 与费用
```

## 排名设计

`MINIMUM_IQ` 是硬门槛。模型必须先达到最低 IQ，才参与前排的性价比比较。

对于有效数据，性价比分数为：

```text
score = IQ / average_price_usd
```

排序键依次为：

1. 是否达到 `MINIMUM_IQ`；
2. 性价比分数（从高到低）；
3. 费用（从低到高，仅在性价比分数相同时作为稳定排序）。

缺失 IQ 或费用的记录固定置后。

## 拖动设计

按下鼠标时记录鼠标相对窗口左上角的偏移量。移动时以当前鼠标绝对坐标减去该偏移量直接定位窗口，不依赖上一帧位置，因此不会出现累计偏移、拖动滞后或反向。

## 自启设计

自启项写入当前用户的 Windows“启动”文件夹，生成 `CodexTierWidget.lnk`，因此只影响当前用户且不需要管理员权限。首次运行会创建指向当前可执行文件的快捷方式；用户通过托盘菜单关闭后，会记录已配置状态，后续手动启动不会擅自重新开启。

冻结为 EXE 时，自启命令使用 `sys.executable`。从源码运行时使用 `pythonw.exe` 和项目启动脚本，避免开机时出现控制台窗口。

## 隐私边界

项目只访问 Codex 雷达的公开实时任务表和降级快照，并只写入自己的数据缓存与当前用户自启设置。不存在 `config.toml` 读取、Codex 控制、模型切换或进程重启逻辑。
