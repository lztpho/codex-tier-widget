# 架构说明

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `widget.py` | 三行紧凑界面、鼠标拖动、刷新与排序 |
| `data.py` | 拉取公开数据、本地缓存、查找模型记录 |
| `color.py` | IQ/费用分数、格式化与辅助颜色 |
| `config.py` | 三个展示档位、IQ 门槛、数据地址与界面尺寸 |
| `scripts/launch_widget.py` | 从项目源码可靠启动悬浮窗 |

## 数据流

```text
启动或十分钟刷新
        ↓
读取 Codex 雷达公开 JSON
        ↓ 失败
读取本机缓存 ~/.codex_radar_cache.json
        ↓
按 model + effort 找到三个档位的 IQ 与费用
        ↓
按 IQ 80 门槛分组，再按 IQ ÷ 费用排序
        ↓
渲染模型短名称、IQ 与费用
```

## 排名设计

`MINIMUM_IQ` 是硬门槛。模型必须先达到最低 IQ，才参与前排的性价比比较。

对于有效数据，性价比分数为：

```text
score = IQ / average_price_usd
```

排序键依次为：

1. 是否达到 `MINIMUM_IQ`；
2. 性价比分数（从高到低）；
3. 费用（从低到高，仅在性价比分数相同时作为稳定排序）。

缺失 IQ 或费用的记录固定置后。

## 拖动设计

按下鼠标时记录鼠标相对窗口左上角的偏移量。移动时以当前鼠标绝对坐标减去该偏移量直接定位窗口，不依赖上一帧位置，因此不会出现累计偏移、拖动滞后或反向。

## 隐私边界

项目只访问 Codex 雷达的公开数据，并只写入自己的数据缓存。不存在 `config.toml` 读取、Codex 控制、模型切换或进程重启逻辑。
